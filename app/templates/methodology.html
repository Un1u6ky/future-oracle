Как считается прогноз

Модель нарочно простая: правила и веса, без чёрного ящика. Нейросеть не участвует в скоринге — только фиксированный лексикон заголовков. Так цифры в карточке можно пересчитать на бумаге.

1. Что прогнозируем

Направление цены актива через 24 часа: up / down / sideways. Это не цена, не доходность и не торговый сигнал.

2. Откуда данные

  • CoinGecko — цена, Δ24ч, Δ7д, объём, high/low, 8-дневный ряд для бэктеста.
  • Alternative.me Fear & Greed — дневной индекс настроения рынка.
  • CryptoCompare + CoinDesk RSS + Cointelegraph RSS — заголовки.

Сырой JSON/RSS кладётся в raw_records, нормализованные поля — в отдельные таблицы.

3. Пять сигналов ∈ [−1; +1]

momentum = 0.65 * clip(Δ24h / 15) + 0.35 * clip(Δ7d / 25)
volume = sign(momentum) * tanh(volume_ratio − 1)
range = clip((0.5 − position_in_24h_range) * 2) # mean reversion
news = Σ (decay * mention_weight * lexicon_sentiment) / Σ weights
f&g = (50 − fear_greed) / 50 # контрарий

Сентимент заголовка: (бычьих фраз − медвежьих) / сумма совпадений. Вес новости затухает с периодом полураспада 18 часов. Рыночные заголовки без тикера получают вес 0.35 на все активы.

4. Сборка

score = 0.28·momentum + 0.18·volume + 0.12·range + 0.25·news + 0.17·f&g
P(up) = sigmoid(3.2 * score)
direction = up если score > 0.12, down если score < −0.12, иначе sideways
confidence = 100 * (0.50*|score| + 0.32*agreement + 0.18*news_coverage) [* 0.85 если vol>8%]

agreement — доля ненулевых сигналов с тем же знаком, что и score. news_coverage = min(1, число заголовков / 5). Уверенность ≠ вероятность: P(рост) — оценка направления, уверенность — насколько сигналы согласованы и свежи.

5. Риск

Риск высокий, если против итогового знака смотрят несколько сигналов, мало новостей, узкий score или широкий внутридневной диапазон. Тексты риска собираются из тех же полей, не из LLM.

6. Как система понимает, что ошиблась

У каждого прогноза есть resolve_after = as_of + 24h и цена на момент расчёта. Когда появляется более поздний снимок:

return = (price_later / price_then − 1) * 100
actual = up если return > +0.5, down если return < −0.5, иначе sideways
was_correct = (direction == actual)
brier = (P(up) − target)² # target 1 / 0 / 0.5

На первом запуске живые 24 часа ещё не прошли — поэтому сразу считается бэктест по дневным свечам CoinGecko за последние 6 дней. Это те же формулы, только as_of сдвинут в прошлое, а новости берутся строго не позже этой даты. Ошибки видны на странице «Ошибки».

7. Что здесь не делается

  • Нет ставок, кошельков, API бирж с ордерами.
  • Нет обещания edge: бэктест короткий и легко врёт.
  • Лексикон грубый — ирония и сарказм ему неподвластны. Это честный риск модели.
